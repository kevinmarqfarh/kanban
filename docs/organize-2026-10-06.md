# Revision 6 oktober 2026 — taggar, nedräkning, fokus och mobil träning

## Vad som ändrats

| Område | Ändring |
| --- | --- |
| Födelsedagar | Taggar (Familj, Vänner, Jobb eller egen tagg via *Lägg till tagg*). Översikten grupperas per tagg. Nedräkningsruta per person med färgad kantlinje (grön ≤ 30 dagar, gul ≤ 14, röd ≤ 7). Dra-och-släpp för ordning och byte av tagg med mus, touch och tangentbord. *Sortera efter datum*. |

| Recept | Bild per recept (förminskas till ≤ 1200 px JPEG) på kortet och i receptet. *Lägg till etikett* direkt bredvid Frukost/Snacks/Middag i stället för ett separat fält. Filter per etikett med antal. |

| Planner | *Ta bort kolumn* för alla kolumner utom Finalized, med val av kolumn att flytta korten till. Datum- och tidsfält i alla formulär har samma storlek som övriga fält på iPhone. |
| Toppraden | Logga till vänster, notiser och kugghjul till höger. Synkstatus och färgtema finns under Inställningar. |

## Data och kompatibilitet

- `Birthday.tag` (`string | null`) är nytt och valfritt. Första gången en äldre arbetsyta laddas sparas den tidigare datumordningen som manuell ordning och alla får `tag: null` — inget hoppar runt. Därefter sorteras listan aldrig om automatiskt. Ordningen är arrayens ordning och slås ihop mellan flikar som tidigare.
- `WorkoutRow.loadUnit` kan nu vara `'level'`. Råtexten skrivs som `nivå 8`.
- `Recipe.image` är en valfri JPEG/PNG/WebP-data-URL (max 700 000 tecken) som appen själv skapar; andra värden avvisas av valideringen.
- Kostens färg räknar bara vanor som fanns det datumet (eller som markerats det datumet). Framtida dagar är neutrala.
- Alla nya fält valideras i `isWorkspace`. Uppgraderingen ligger i `migrateWorkspace` och körs vid varje laddning (idempotent).
- Ett tryck som börjar i ett ark och släpps utanför stänger inte längre arket (gäller alla dialoger).

## Verifiering

- `npm run check`, `npm test` (inkl. nya `tests/tags-and-tracking.mjs`) och `npm run build` passerar.
- Ny webbläsarsvit `tests/organize-acceptance.cjs` (33 scenarier) passerar i Chromium: taggning, enter/escape i taggrutan, mus-, touch- och tangentbordsdrag, tomma släppytor, ingen layoutförskjutning under fingret på iPhone, sortering, Home-filter, layout utan sidoscroll vid 320/375/430 px, helskärmsanteckning på desktop och iPhone, fet/kursiv och formateringsrad, svep-för-att-ta-bort med touch och mus samt Ångra, kostfärger i Kost och Home, träningsförslag och Nivå, 16 px/44 px på mobil samt receptetiketter och filter.
- Befintliga sviter (acceptance, birthdays, debriefs, notes, others, projects, revision, offline) passerar i Chromium. Äldre förväntningar som inte räknat med den automatiska Finalized-kolumnen och den explicita birthday-taggen är uppdaterade.
- WebKit kunde inte installeras i byggmiljön; kör `BROWSER_ENGINE=webkit npm run test:organize` lokalt för Safari-motorn.
